How to read this page

Each weapon class lists its best attribute priorities for a solo crit/DPS build, and every weapon talent that can roll on that class — universal talents (work on anything) plus talents locked to that class or class group. Verdicts (Keep / Situational / Skip) match the Talent Lookup page. Attribute guidance assumes a weapon-damage build; skill and tank builds prioritise differently — see the Builds page.

Read me: attribute priority guidance is general build wisdom, not patch-exact numbers — confirm specific god-roll targets against a live source before recalibrating gear. Talent data mirrors the Talent Lookup page (39 rollable weapon talents from The Division Wiki); named/exotic-locked talents are excluded. "Universal" talents work on any weapon but are surfaced per class because how well they perform depends on that class's fire rate, mag size and range band.
