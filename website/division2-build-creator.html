Database Backup

Everything you import or edit here lives in this browser's local storage — it is not saved to a file on its own. Export a backup after any import or editing session, and keep it somewhere safe. Restoring replaces the entire working database with the contents of the backup file.

Import Build

Paste one build object, several comma-separated, or the whole const BUILDS = [ … ] array — e.g. copied straight out of division2-builds.html. Slots get matched back to your database where possible (by set name and exotic flag); anything that can't be matched is still loaded with its original text intact, it just won't show as pre-selected in that slot's dropdown.
