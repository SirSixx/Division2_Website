Database Backup

Everything you import or edit here is saved to the server automatically, and every change keeps the previous version in the database's history. Export a full backup (all datasets and builds) now and then and commit it to the repo's website/snapshot/ folder. Restore accepts either that export or an old local-storage backup file from before the migration; it replaces the gear / brand / named databases (builds are not touched).

Import Build

Paste one build object, several comma-separated, or the whole const BUILDS = [ … ] array — e.g. copied straight out of division2-builds.html. Slots get matched back to your database where possible (by set name and exotic flag); anything that can't be matched is still loaded with its original text intact, it just won't show as pre-selected in that slot's dropdown.
